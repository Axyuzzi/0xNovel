# 0xNovelAgent 品牌图形

- `source/0xnovelagent-app-mark.svg`：用户提供的蓝黑 `0x` 矢量原稿。
- `source/0xnovelagent-wordmark-pair.png`：用户提供的黑白横向 Logo 合并原稿。
- `0xnovelagent-app-icon.png`：方形应用图标母版，供 Electron、客户端和官网生成各尺寸图标。
- `0xnovelagent-wordmark-dark.png`：透明底深色横向 Logo，适合浅色界面。
- `0xnovelagent-wordmark-light.png`：透明底浅色横向 Logo，适合深色界面。
- `0xnovelagent-logo-dark-on-light.png` 与 `0xnovelagent-logo-light-on-dark.png`：拆分后的方形预览图。

运行 `python desktop/scripts/generate-desktop-icons.py` 可从品牌母版同步生成桌面 `.ico`、客户端 favicon、Web App 图标和官网图标。
