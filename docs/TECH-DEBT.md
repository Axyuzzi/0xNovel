# 技术债务清单

> 最后更新：2026-07-28

## 高优先级

### 2026-07-28 商业授权与 AGPL 上线路线未确认

- **位置**：`LICENSE`、`NOTICE`、`CLA.md`、桌面发布物与未来中转 SaaS
- **问题**：原项目采用 `AGPL-3.0-only` 并明确写有服务型商用需另行授权；当前没有可验证的书面商业许可，也没有经过律师确认的 AGPL 履约上线方案。
- **影响**：删除原作者地址或更换品牌不能产生闭源商业化权利；在解决前收费发布桌面版或 SaaS 存在重大版权与许可证风险。
- **优先级**：P0
- **处理**：先核实 `NOTICE`、Git 作者、仓库账号和历史贡献者的权利链；再取得覆盖桌面端、中转服务、修改、收费与再分发的书面授权，或完成律师确认的 AGPL 开源履约路线。
- **关联**：[商业 SaaS 风险审计](wiki/security/commercial-saas-risk-audit.md)

### 2026-07-28 C 端外部请求尚未统一收口

- **位置**：内置模型 Provider、自定义 Provider、Webhook、RAG、S3、图片、TTS 与视频服务
- **问题**：旧 B 端能力允许访问多种内置或用户自定义地址；当前桌面版默认配置不会联系原作者，但尚未形成 C 端统一出口和域名白名单。
- **影响**：如果直接作为远程 SaaS 暴露，会产生数据外发、计费绕行和 SSRF 风险。
- **优先级**：P0
- **处理**：普通 C 端模式只允许本地服务、自有中转和自有更新站；专家能力必须隔离、显式启用并经过出口校验。
- **关联**：[商业 SaaS 风险审计](wiki/security/commercial-saas-risk-audit.md)

## 中优先级

暂无。

## 低优先级

### 2026-07-17 兼容环境变量仍使用历史命名

- **位置**：`AI_NOVEL_*` 兼容环境变量
- **问题**：部分本地运行和发布配置仍保留历史环境变量名。
- **影响**：这些名称不产生网络请求，也不会通知原作者，但增加配置理解成本。
- **优先级**：低
- **关联**：后续在完成 C 端新运行时切换后统一迁移。

## 已解决

### 2026-07-17 主仓库与桌面更新源脱离原 GitHub

- 主仓库已切换到私有 Gitee，原 GitHub 只保留为禁止推送的本地 `upstream` 参考。
- 桌面包不再生成指向原 GitHub Releases 的更新配置；只有显式提供自有通用更新地址时才启用自动更新。

### 2026-07-28 原公开站路径与原作者 CLA 链接清理

- 公开站不再硬编码原作者 GitHub Pages、旧仓库路径、canonical、sitemap 或社交分享地址。
- 未配置 `OXNOVEL_PUBLIC_SITE_URL` 时不会生成绝对公开地址；配置后只使用自有站点。
- 删除未使用的第三方 GitHub 星标代理请求，并在站点与桌面发布前执行遗留外联检查。
- Pull Request 模板不再指向原作者 CLA；自有商业授权和 CLA 主体完成前不合并外部代码贡献。
